# src/pages/api/track.ts — 사용성 집계 수집구 (U-3)

## 계약

`POST /api/track`, 본문 `{ events: [{ event, page?, props?, at? }] }`. 응답은 **언제나 204**.

무엇이 걸러졌는지 알려 주면 허용목록을 탐색하는 통로가 된다. 성공·실패·거절을 구분해 주지 않는다.

## 신뢰 경계

| 클라이언트가 주는 것 | 서버가 하는 일                              |
| -------------------- | ------------------------------------------- |
| 이벤트 이름          | `recordUsage` 가 허용목록으로 거른다        |
| 속성                 | 키·값 모두 허용목록으로 거른다              |
| 경로                 | 제외 접두 판정 후 질의문자열 제거·길이 제한 |
| 발생 시각            | 미래·7일 초과 과거면 수신 시각으로 대체     |
| **신원**             | **받지 않는다.** 세션 쿠키에서 직접 읽는다  |

신원을 본문에서 받지 않는 것이 핵심이다. 받으면 아무나 남의 활동을 만들어 낼 수 있다.

## 상한

- 한 요청 20건까지. 나머지는 버린다
- 본문 16KB 초과면 읽지 않고 204
- 둘 다 클라이언트와 같은 값이라 정상 사용에서는 잘릴 일이 없다

## 실패 처리

본문이 깨졌거나 세션 조회가 실패해도 오류를 돌려주지 않는다. 집계는 부수 기능이고, 여기서 4xx·5xx 를 내면 브라우저 콘솔에 오류가 쌓여 진짜 문제를 가린다.
