# src/pages/api/admin/usage.ts — 관리자 사용 현황 데이터

## 왜 엔드포인트가 필요한가

집계 표는 서비스 롤 전용이다(RLS 정책 없음). 브라우저가 직접 읽을 수 없다. 그래서 관리자 확인을 거친 이 엔드포인트가 대신 읽어 준다 — 다른 관리자 화면과 같은 방식(화면은 fetch)을 유지한다.

## 내주는 것과 내주지 않는 것

|               |                                                                               |
| ------------- | ----------------------------------------------------------------------------- |
| 내준다        | `usage_daily` · `usage_page_daily`(최근 30일) · `usage_active`(현재 일·주·월) |
| 내주지 않는다 | **원시 이벤트**                                                               |

원시를 브라우저로 흘리면 시각과 경로가 한자리에 모여 추정 가능성이 올라간다. 화면에 필요한 것은 합계뿐이다.

## 권한

로그인하지 않으면 401, 관리자가 아니면 403. 판정은 세션 쿠키에서 읽은 사용자로 `profiles.is_admin` 을 확인한다 — 클라이언트가 보낸 값을 쓰지 않는다.
