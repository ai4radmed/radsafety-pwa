# 명세: src/pages/admin/verification-requests.astro

## 역할 요약

회원 인증 및 권한 관리 페이지. 사용자의 인증 상태를 탭별로 조회하고, 인증 요청에 대한 승인·인증 취소 처리를 수행합니다.

## Props

없음.

## 사이드 이펙트

- `profiles` 테이블 업데이트: 인증 상태(`verification_status`), 관리자 여부(`is_admin`) 등 변경.
- `verification_requests` 테이블 업데이트: 요청 상태 및 승인/반려 기록.
- `notifications` 테이블: 승인/취소 결과 알림 발송.

## 핵심 규칙

1. **접근 제어**: `is_admin` 권한이 있는 사용자만 접근 가능.
2. **동적 렌더링**: `export const prerender = false`.
3. **탭 구성 및 명칭**:
    - **임시인증** (`temp_verified`): 이메일 인증 완료 후 관리자 승인 대기 중인 사용자.
    - **관리자인증** (`verified`): 관리자가 수동으로 승인 완료한 사용자. (구 '최종인증')
    - **인증취소** (`rejected`): 인증 요청이 반려되었거나 권한이 회수된 사용자.
    - **명부인증** (`list`): 학회 명단 대조를 통해 자동 인증된 사용자.
    - **미인증** (`none`): 인증 프로세스를 시작하지 않았거나 아직 신청하지 않은 **전체 가입자**.
4. **미인증 탭 데이터 로드**:
    - 다른 탭과 달리 `society_email`이 `null`인 사용자(단순 가입자)도 모두 포함하여 표시합니다.
5. **데이터 연동**:
    - `verification_requests`와 `profiles` 테이블을 `user_id` 기준으로 결합하여 상세 정보(신청 사유 등)를 표시합니다.
6. **동작**:
    - 승인(확정): '임시인증' ➔ '관리자인증'으로 변경.
    - 취소(반려): '임시인증' ➔ '인증취소'로 변경 (취소 사유 입력 필수).
    - 회수: '관리자인증' ➔ '임시인증'으로 되돌리기.
