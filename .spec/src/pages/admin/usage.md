# src/pages/admin/usage.astro — 사용 현황(관리자)

## 무엇을 보여 주나

1. **활성 회원** — 오늘 · 이번 주 · 이번 달
2. **회원 전용 벽 이탈** — 벽을 만남 → 로그인 화면 도달 → 가입 신청 → 가입 승인
3. **많이 열린 화면** — 무엇을 더 만들지의 직접 신호
4. **가장 많이 벽을 만든 화면** — 비회원 수요가 큰 곳. 공개로 돌릴지 판단하는 근거
5. **기능별 사용**

## 읽는 법에서 틀리기 쉬운 것

**활성 회원은 기간 안에서 합산하지 않는다.** 날짜를 넘어 같은 사람을 이을 수 없으므로 일자별 활성자를 더하면 같은 사람을 여러 번 세게 된다. 그래서 기간 표에서는 **그 기간 중 하루 최대 인원**을 보여 주고, 진짜 주간·월간 인원은 위의 카드(주·월 키로 센 값)를 본다.

"오늘/이번 주/이번 달"은 **달력 기준**이지 직전 7일·30일이 아니다. 주는 ISO 주차(월요일 시작)다.

**비로그인 방문자는 "회원 수"에 없다.** 서로 구분할 수단이 없기 때문이다. 조회 수에는 들어간다.

## 가리기

`USAGE_MIN_DISPLAY_COUNT` 미만은 `<N` 으로 가린다. 기본 0 = 가리지 않음. 화면을 관리자 밖에 보여 줄 일이 생기면 올린다.
