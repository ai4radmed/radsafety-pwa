## 핵심 규칙

1. **화면과 어긋나면 안내가 거짓이 된다** — 기능을 바꾸는 PR 은 같은 PR 에서 이 문서를 고친다. 특히 메뉴가 늘거나 권한 규칙이 바뀔 때.
2. **없어진 기능을 적지 않는다**: 이메일 OTP 로그인, 학회 명부 대조 인증(자동·특별사용자·재인증), 닉네임·이메일 표시, 면허·선임 카드는 모두 폐지됐다.
3. 회원 전용 절에는 `<span class="member-only">회원 전용</span>` 배지를 단다.
4. 비회원 이용 범위(1절)는 `auth-handler.ts` 의 `publicPaths` 와 일치해야 한다.
5. 자료실 Slug 설명·개선의견조회 3상태(검토중/보류/완료)는 유지한다.
