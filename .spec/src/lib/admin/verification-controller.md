# 명세: src/lib/admin/verification-controller.ts

## 역할 요약

인증 관리 페이지의 클라이언트 측 비즈니스 로직 및 UI 제어를 담당하는 클래스 또는 모듈입니다.

## 주요 기능

1. **데이터 로드 (`loadUsers`)**: Supabase를 통해 특정 상태의 사용자 목록을 비동기적으로 가져옴.
2. **UI 렌더링 (`renderUsers`)**: 가져온 데이터를 테이블 HTML로 변환하여 주입.
3. **검색 및 필터링 (`filterUsers`)**: 이름, 이메일, 소속 등을 기준으로 목록 필터링.
4. **액션 처리 (`approve`, `reject`, `revoke`)**: Astro Actions 및 Supabase Notification API를 호출하여 상태 변경 수행.
5. **상태 관리**: 현재 선택된 탭 정보 및 전체 사용자 데이터를 메모리에 유지.
6. **카운트 업데이트 (`updateCounts`)**: 각 상태별 총 사용자 수를 실시간(또는 페이지 로드 시) 갱신.

## 핵심 규칙

1. **에러 핸들링**: 모든 비동기 작업 시 사용자에게 alert 또는 UI를 통해 오류 상황 전파.
2. **성능**: 탭 전환 시 불필요한 전체 페이지 리로드 방지.
3. **데이터 정렬**: 최신 상태 변경일 기준으로 정렬하여 표시.
