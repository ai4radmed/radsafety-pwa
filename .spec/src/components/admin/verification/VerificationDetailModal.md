# 명세: src/components/admin/verification/VerificationDetailModal.astro

## 역할 요약

선택된 사용자의 상세 정보를 보여주고 승인/반려/회수 액션을 수행하는 모달 컴포넌트입니다.

## Props

없음

## 핵심 규칙

1. **정보 표시**: 이메일, 부서, 신청 사유(또는 취소 사유) 등을 표시.
2. **동적 액션 버튼**: 사용자의 현재 상태에 따라 하단 버튼 구성이 변경됨.
    - `temp_verified`: 닫기, 취소, 확정.
    - `verified`: 닫기, 임시인증으로 되돌리기.
    - 기타: 닫기.
3. **취소 사유 입력**: 취소 버튼 클릭 시 취소 사유를 입력할 수 있는 텍스트 영역이 나타나야 함.
4. **접근성**: 닫기 버튼 및 오버레이 클릭 시 닫기 기능.
