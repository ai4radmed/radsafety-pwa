# 명세: src/components/admin/verification/VerificationTable.astro

## 역할 요약

사용자 목록을 출력하는 테이블 컴포넌트입니다.

## Props

없음 (데이터는 클라이언트 컨트롤러를 통해 동적으로 주입됨)

## 핵심 규칙

1. **테이블 구조**: 이름, 소속, 구분, 상태변경일(동적 헤더) 4개 컬럼으로 구성.
2. **데이터 영역**: `id="usersTableBody"`를 가지는 `<tbody>` 요소에 결과가 렌더링됨.
3. **빈 상태 처리**: 데이터가 없을 경우 `colspan="4"`인 행에 "해당 상태의 사용자가 없습니다." 등의 메시지 표시.
4. **상호작용**: 각 행(`<tr>`)은 `data-user-id`를 가지며, 클릭 시 상세 모달이 열려야 함.
