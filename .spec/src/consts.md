# 명세: src/consts.ts

## 역할 요약

전역 상수 데이터를 정의하는 모듈. 사이트 제목·설명, 앱 버전·릴리스 날짜 등 프로젝트 전역에서 재사용되는 값을 단일 소스로 제공한다.

## Public API

| 이름               | 타입     | 설명                                              |
| ------------------ | -------- | ------------------------------------------------- |
| `SITE_TITLE`       | `string` | 사이트 브랜드명 (`'RadSafety'`)                   |
| `SITE_DESCRIPTION` | `string` | 사이트 메타 설명 (`'RadSafety Official Website'`) |
| `APP_VERSION`      | `string` | 앱 버전 표기 (릴리스마다 갱신; 사이드바·로그 등 공통 사용) |
| `APP_RELEASE_DATE` | `string` | 해당 버전 기준 배포 날짜 `YYYY-MM-DD` (릴리스마다 갱신)   |

## 사이드 이펙트

없음. 순수 상수 export만 수행한다.

## 핵심 규칙

1. `import` 키워드로 프로젝트 어디서든 참조 가능하다.
2. 런타임 변경이 필요한 값은 이 파일에 두지 않는다.
3. **버전 정보(`APP_VERSION`·`APP_RELEASE_DATE`)는 이 파일 한 곳에만 정의**하고, UI(사이드바·마이페이지)·로그에서 노출 시 반드시 이 상수를 import 해 사용한다(하드코딩 금지).
4. 새 전역 상수 추가 시 이 명세를 먼저 갱신한다.
