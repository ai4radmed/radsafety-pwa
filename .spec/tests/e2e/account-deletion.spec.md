## Mock/Setup

- 인증된 사용자: `storageState` 또는 로그인 플로우로 마이페이지 접근 가능 상태.
- 실제 계정 삭제는 수행하지 않음: 확인 대화상자에서 취소(dismiss)하여 검증만 수행.

- 회원 탈퇴 버튼이 모달 밖 메인 영역에 노출되는지 및 확인 UX 회귀 방지.
