# 테스트 명세: 인증관리 E2E 테스트

## 목적

관리자 페이지의 '인증관리'(구 인증요청 검토) 페이지가 정상적으로 동작하는지 확인합니다.

## 테스트 시나리오

1. **접근 및 명칭 확인**
    - `/admin/verification-requests` 접속 시 제목이 "인증관리"여야 함.
    - 탭 중 "관리자인증"이 존재해야 함.

2. **미인증 탭 동작 확인**
    - "미인증" 탭 클릭 시 목록이 표시되어야 함.
    - (모의 데이터가 있는 경우) `society_email`이 없는 단순 가입자도 목록에 나타나는지 확인.
    - 날짜 헤더가 "가입일"로 변경되었는지 확인.

3. **탭 전환 및 데이터 로딩**
    - 각 탭(임시인증, 관리자인증, 인증취소, 명부인증, 미인증) 전환 시 "로딩 중..." 메시지가 사라지고 데이터가 표시되는지 확인.

4. **승인/취소 액션**
    - 임시인증 상태의 사용자 상세 모달에서 "확정" 클릭 시 "관리자 인증으로 승인하시겠습니까?" 컨펌창이 뜨는지 확인.
    - 관리자인증 상태의 사용자 상세 모달에서 "임시인증으로 되돌리기" 클릭 시 동작 확인.
