# 테스트 명세 — `scripts/health-report.mjs`

대상 구현체: `scripts/health-report.mjs`
테스트 구현체: `tests/unit/scripts/health-report.test.ts`

## 역할

`check-production.mjs --summary=<path>` 가 남긴 요약 JSON 을 읽어 **텔레그램 보고 문안**을 만들고 발송한다.
발송(네트워크)은 부작용이므로 **문안 생성(`formatReport`)만 순수 함수로 분리**하고, 단위 테스트는 이 함수만 검증한다.

## 보고 모드 (`HEALTH_REPORT` 저장소 변수)

| 값             | 동작                                        |
| -------------- | ------------------------------------------- |
| 미설정 · `all` | 정상·이상 모두 매일 발송 (기본, 하트비트)   |
| `fail`         | 이상일 때만 발송 (정상은 침묵)              |
| `off`          | 발송하지 않음 (헬스체크·GitHub 알림은 유지) |

## `formatReport(summary, opts)` 검증 항목

1. **정상 요약** → `✅` 로 시작하고, 대상 호스트 · 통과 건수 · 앱 버전을 포함한다.
2. **실패 요약** → `❌` 로 시작하고, 실패 항목 라벨과 detail 을 본문에 나열한다.
3. **경고(warned>0, failed=0)** → 정상(`✅`)으로 보고하되 경고 건수를 함께 표기한다.
4. **시각 표기** — `checkedAt`(ISO/UTC)을 **Asia/Seoul** 로 변환해 표기한다(UTC 원문 노출 금지).
5. **실패 항목 절단** — 실패가 10건을 넘으면 10건까지만 나열하고 잔여 건수를 `…외 N건` 으로 표기한다(텔레그램 메시지 길이 보호).
6. **요약 누락(`summary === null`)** — 점검 스크립트가 요약을 남기기 전에 죽은 경우로 간주하고, `❌` + "점검 실행 자체 실패" 문구를 낸다. **정상으로 오인해선 안 된다.**
7. **실행 로그 링크** — `opts.runUrl` 이 주어지면 본문에 포함한다.
8. **영역별 문안(`summary.sections` + `summary.highlights`)** — 요약에 영역 집계가 있으면 "N건 통과" 대신 **영역별 상태 줄**(🌐 접속 / 🔒 인증서 / 📄 화면 / 🚧 접근차단 / 🔑 로그인 경로 / 🔌 API / 🩺 자가진단 / 🖥 브라우저)을 사람 말로 보여준다. 인증서 잔여일·홈 응답속도 같은 수치를 함께 표기. `deep`/`shallow` 는 "전체 점검"/"기본 점검"으로 풀어 쓴다(개발자 용어 노출 금지). 그룹 매핑에 없는 새 영역은 원래 이름으로 표기(조용한 누락 방지). sections 없으면(구버전 요약) 기존 "N건 통과" 문안으로 폴백.
    - **세부 항목 나열(`sections[].items`)** — 각 영역 줄 아래에 항목명을 `   ✓/⚠/✗` 들여쓰기로 나열. 정상 항목은 이름만(수치 detail 은 소음), 경고·실패 항목은 사유(detail)까지. 스모크 통과 시 브라우저 영역 아래 홈·로그인 2개 항목을 고정 표기(테스트 구성 변경 시 함께 갱신).
9. **브라우저 스모크 결합(`opts.smoke`)** — 워크플로의 Playwright 스모크 결과가 별도 스텝(`SMOKE_OUTCOME` env)으로 주입된다.
    - `'success'` + 요약 정상 → `✅` 유지, "브라우저 스모크 통과" 표기.
    - `'failure'` → **요약이 정상이어도 `❌` 이상 감지**로 승격하고 실패 목록에 스모크 항목을 추가한다(JS 크래시 백지 화면은 HTTP 점검에 안 보이므로).
    - `undefined`(미주입 — 구버전 워크플로·로컬) → 문안에 스모크를 언급하지 않는다(하위 호환).

## `shouldSend(summary, mode, smoke)` 검증 항목

- `off` → 항상 false.
- `fail` → 정상이면 false, 실패·요약누락·**스모크 실패**이면 true.
- `all`·미설정 → 항상 true.
