# 테스트 명세: src/pages/guide.astro (이용안내 현황 일치)

## 대상 구현체

- 경로: src/pages/guide.astro
- 명세: .spec/src/pages/guide.md

## 테스트 도구

Vitest (파일 소스 읽기).

## 배경

옛 테스트는 `선임기간` 라벨 존재를 요구했다 — 그 라벨이 속한 **방사선안전관리정보 카드는 2단계 2-2 에서 폐지**됐으므로, 이제는 "폐지된 기능이 안내에 남아 있지 않은가"를 검증한다(2026-09-20 전환).

## 검증 항목

| describe                      | it                                                         | 검증 내용                                                |
| ----------------------------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| 폐지된 기능을 안내하지 않는다 | 면허·선임 정보 입력 안내가 없다                            | `선임기간`·`면허 및 선임`·`방사선안전관리정보 카드` 부재 |
| 폐지된 기능을 안내하지 않는다 | 학회 이메일 대조 인증 절차 없음                            | 자동 검증·관리자 인증 요청·특별사용자·재인증 문구 부재   |
| 폐지된 기능을 안내하지 않는다 | 카카오 닉네임·이메일 표시 안내 없음                        |                                                          |
| 현재 규칙을 담는다            | 로그인은 아이디/비밀번호와 카카오 둘뿐                     |                                                          |
| 현재 규칙을 담는다            | 가입 승인 = 게시 권한, 아이디 변경 불가·비밀번호 변경 가능 |                                                          |
| 현재 규칙을 담는다            | 비회원 이용 범위를 1절에 적는다                            | `auth-handler.publicPaths` 와 일치해야 함                |
