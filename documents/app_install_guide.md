# RadSafety 앱 설치 안내 (PC·스마트폰)

이 문서는 **PC와 스마트폰에서 RadSafety PWA를 설치하는 방법**을 한 번에 정리한 가이드입니다.

- **RadSafety는 PWA(Progressive Web App)** 이므로, 설치 후에는 일반 앱처럼 아이콘으로 실행할 수 있고, 주소창 없이 전체 화면으로 사용할 수 있습니다.
- iOS(아이폰) 전용 상세 설명은 별도 문서인 `ios_installation.md`에 있습니다. 여기서는 **공통 개념 + 플랫폼별 차이**만 정리합니다.

---

## 1. 공통 개념 — “설치”란 무엇인가?

1. 브라우저에서 `https://radsafety.kr` 에 접속합니다.
2. 브라우저가 이 사이트를 “설치 가능한 앱(PWA)”로 인식하면, **설치 버튼 또는 "홈 화면에 추가" 메뉴**가 나타납니다.
3. 설치를 완료하면:
    - 홈 화면(모바일) 또는 시작 메뉴/작업 표시줄(PC)에 **RadSafety 아이콘**이 생기고,
    - 이후에는 이 아이콘을 눌러 **바로 앱을 실행**할 수 있습니다.

> [!IMPORTANT]
> 설치 후에는 **반드시 해당 아이콘으로 실행**해야 합니다. 특히 iOS에서는 Safari 주소창이 보이지 않는 전체 화면 모드로 열려야 세션·푸시 알림 등이 정상 동작합니다.

---

## 2. PC에서 설치 (크롬/엣지 기준)

### 2-1. 설치 절차

1. **사이트 접속**
    - 크롬 또는 엣지에서 `https://radsafety.kr` 에 접속합니다.
2. **설치 버튼 확인**
    - 주소창 우측에 **"앱 설치"(모니터 + 다운로드 아이콘)** 가 보일 수 있습니다.
    - 또는 브라우저 메뉴(⋮ 또는 …) 안에 **"RadSafety 설치" / "앱 설치" / "이 사이트를 앱으로 설치"** 와 같은 항목이 나타납니다.
3. **설치 진행**
    - 해당 메뉴를 클릭하고, 확인 대화상자에서 **[설치]** 를 누릅니다.
4. **아이콘 실행**
    - 설치가 완료되면 RadSafety가 별도 창으로 열리며,
    - Windows의 경우 **시작 메뉴**나 **작업 표시줄에 고정**하여 사용할 수 있습니다.

### 2-2. 카카오 로그인 관련 참고

- PC 브라우저에서 **이미 카카오 웹에 로그인되어 있고, RadSafety에 한 번 동의한 계정**이라면:
    - 로그인 페이지에서 "카카오로 시작하기"를 누르는 즉시 **추가 화면 없이 `/mypage`로 바로 이동**할 수 있습니다.
- 완전히 처음처럼 테스트하고 싶다면:
    - PC 브라우저에서 `https://accounts.kakao.com` 에 접속해 **로그아웃**하거나,
    - 브라우저의 사이트 데이터(쿠키)를 삭제한 뒤 다시 시도합니다.

---

## 3. 스마트폰에서 설치 (요약)

스마트폰 설치는 플랫폼마다 UI가 다르므로, 여기서는 **핵심 흐름만 요약**하고 iOS의 상세 절차는 `ios_installation.md`를 참고하도록 합니다.

### 3-1. iPhone (Safari)

> **자세한 단계별 스크린샷과 예시는 `ios_installation.md` 문서를 참고하세요.**

1. **Safari에서 `radsafety.kr` 접속**
2. 하단의 **공유(□↑) 버튼** 탭
3. 메뉴에서 **"홈 화면에 추가"** 선택
4. 아이콘 이름 확인 후 **[추가]**
5. 홈 화면의 **RadSafety 아이콘으로 실행** (주소창이 없어야 정상 설치)

> [!WARNING]
> 카카오톡/이메일 앱 내부 브라우저에서는 "홈 화면에 추가"가 제대로 동작하지 않을 수 있습니다.
> 반드시 **Safari로 열기** 후 설치해야 합니다. 이 부분은 `ios_installation.md`에 자세히 설명되어 있습니다.

### 3-2. Android (Chrome)

1. **Chrome에서 `radsafety.kr` 접속**
2. 주소창 또는 메뉴(⋮)에서 **"RadSafety 설치" / "홈 화면에 추가"** 항목 선택
3. 안내에 따라 아이콘을 추가한 뒤, 홈 화면에서 해당 아이콘으로 실행

---

## 4. 설치 후 확인 사항

설치가 제대로 되었는지 다음 항목으로 확인할 수 있습니다.

- **공통**
    - 앱 실행 시 브라우저 주소창이 보이지 않고, **독립 창 / 전체 화면**으로 열린다.
    - 사이드 메뉴 하단에 **앱 버전 (예: v0.2.0)** 이 표시된다.

- **iOS**
    - 홈 화면 아이콘에서 실행했을 때만 푸시 알림 및 세션 유지가 안정적으로 동작합니다.

- **PC**
    - 작업 표시줄/시작 메뉴에서 RadSafety를 일반 앱처럼 실행할 수 있습니다.

## 5. 문제 해결(FAQ)

### Q1. 홈 화면에 추가했는데도 주소창이 보입니다.

- iOS의 경우 **북마크**로 추가된 것일 수 있습니다.
- `ios_installation.md` 문서의 "방법 1. Safari에서 직접 접속" 절차를 따라, Safari 앱에서 다시 `radsafety.kr`을 연 뒤 **[공유] → [홈 화면에 추가]** 를 수행하세요.

### Q2. 카카오 로그인 버튼을 눌렀더니 바로 `/mypage`로 들어갑니다. 정상인가요?

- 네. PC 브라우저에서 **이미 카카오 계정에 로그인되어 있고, RadSafety에 대한 동의를 마친 상태**라면 카카오는 다시 로그인/동의 화면을 보여주지 않고 바로 앱으로 돌려보냅니다.
- 완전 신규 가입 흐름을 테스트하고 싶다면 카카오 웹에서 로그아웃하거나, 브라우저 쿠키를 삭제한 뒤 시도하세요.

### Q3. iPhone에서 앱을 껐다 켜면 가끔 로그인이 풀린 것처럼 보입니다.

- 최신 버전(0.2.0 이후)에서는 PWA 설정(iOS용 메타태그, 매니페스트)이 보완되어, 홈 화면 아이콘에서 실행할 경우 세션 유지가 개선되었습니다.
- 여전히 문제가 반복된다면, **Safari에서 사이트 데이터 삭제 후 앱을 재설치**하고 다시 시도해 주세요.
